# UserDO へのリクエストは Worker でユーザーごとに 10 秒 100 回までに制限する

画面や MCP クライアントのループするバグ、あるいはユーザーによる連続の書き込みで UserDO へのリクエストが膨らみ、Durable Object のリクエストと実行時間の課金が想定外に増えることを防ぎたい（Issue #82）。

そこで、Cloudflare の Workers Rate Limiting バインディング（`wrangler.jsonc` の `ratelimits`、`USER_RATE_LIMITER`）で、**ユーザーごとに 10 秒で 100 回**（平均 10 req/s）までに制限する。超えたら UserDO を呼ばずに 429 と `RATE_LIMITED` と `Retry-After: 10` を返す。

- **数える場所は Worker**。DO の中で数えると、弾くリクエストも DO に届いた時点で課金されるので意味がない。Worker で弾けば DO のリクエストは増えない。
- **キーはユーザー ID**。ログイン（`requireSession`）の直後に `limitRequestsPerUser` を置き、`/api/*` の認証必須のエンドポイント（同期の WebSocket の接続を含む）をまとめて守る。MCP（`/api/mcp`）はトークンからユーザーを決めたあとに同じキーで数えるので、画面と MCP の合計で 100 回になる。UserDO はユーザーごとに1つ（ADR 0002）なので、守りたい単位とキーが一致する。
- **10 秒 100 回の根拠**。人が操作する限り、画面を開いたときの読み込み（数件）、操作、記入を合わせても 10 秒に 100 回には届かない。一方、ループするバグは 1 秒に数十〜数百回のリクエストを出すので、それを平均 10 req/s で頭打ちにできる。バインディングの窓は 10 秒か 60 秒しか選べないため、「10 req/s」を 1 秒の窓ではなく 10 秒の窓で表し、読み込み時の一時的な集中を許す。

## Consequences

- 制限に当たったときの課金の上限が見積もれる。1 ユーザーが制限ぎりぎりで 1 か月走り続けても、DO のリクエストは約 2,600 万回に収まる。上限が無ければループの速さだけ増える。とはいえゼロにはならないので、課金のアラート（Cloudflare の Billing の通知）は別に設定しておく。
- バインディングの数え方は Cloudflare の拠点ごとで、結果整合でもある。厳密に 100 回目で止まるとは限らず、正確な会計ではなく「暴走を頭打ちにする」ための仕組みと割り切る。
- 画面は 429 を `ApiRejected`（`RATE_LIMITED`）として受け取る。人の操作で当たることは想定していないので、専用の表示は作らない。同期の WebSocket は繋ぎ直しのたびに待つ時間を延ばすので、429 が続いても接続を繰り返し続けることはない。
- 未ログインのリクエスト（ログインの入口、ヘルスチェック、MCP のトークンなし）は数えない。これらは UserDO に届かず、D1 と Worker の課金だけで済む。必要になったら、IP をキーにした WAF のレート制限ルールを足す。
- UserDO の中から始まるループ（alarm を張り続けるなど）はリクエストではないので、この制限では止まらない。alarm は自動終了の時刻にだけ張る（`user-do.ts` の `#run`）。
- Node のテスト（`auth-test-harness.ts`）は Rate Limiting バインディングを動かせないので常に通す偽物を渡し、制限は Workers のテスト（`rate-limit.workers.test.ts`）で確かめる。

## Considered Options

- **UserDO の中で数える**: 状態を正確に持てるが、弾くリクエストも DO に届いて課金される。目的に合わないので不採用。
- **書き込みだけを制限する**: 読み込みのループ（画面の再描画のたびに取り直すなど）も同じように課金を増やすので、読み書きを区別せず数える。
- **より厳しい上限（例: 10 秒 30 回）**: 課金の上限は下がるが、画面の読み込みが重なったときや、複数の端末を同時に開いたときに人の操作で当たりうる。最初は緩めにし、実際のリクエスト数を見て下げる。
- **WAF のレート制限ルール**: IP やパスで数えるため、ユーザー単位で数えられず、同じ IP の別ユーザーを巻き込む。無料プランではルールの数にも限りがある。ユーザー単位の制限はコードで書く。
